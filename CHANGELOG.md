## 1.2.0 (2026-10-17)

### Upgrade notes

* **Docker image:** `ghcr.io/ozantunca/notion-help-center` is now published for every release. Use the `:1` tag to get new features and fixes without breaking changes. See [Upgrading](./README.md#upgrading).
* **Database:** on the first start, the app copies your database to `help-center.db.backup-v0` in the data volume, then records schema version 1. Nothing else changes in your data, and you do not need to run anything.
* **Running your own Docker setup:** the official image runs as the `node` user (uid 1000). On start it fixes the owner of `/app/data`, `/app/media` and `/app/public`, so volumes created by root-owned containers keep working.
* No environment variables, URLs or volume paths changed.
